# Principles & Techniques of Data Science Coursework (UC Berkeley Data 100)

Write-ups of the two-part projects I completed in **Data 100: Principles and Techniques of Data Science** at UC Berkeley (Summer 2024). The course covers the full data science workflow: cleaning, exploratory analysis, feature engineering, regression, classification and model evaluation.

> **About the code:** the course reuses its projects and asks students not to share solutions, so each folder explains the problem, my approach, results and skills instead of posting the notebooks. I'm happy to walk through the code in an interview.

|---|---|---|---|
| 1 | [Cook County Housing Price Prediction](01-cook-county-housing-price-prediction/) | EDA, feature engineering, linear regression, fairness | pandas, scikit-learn, Seaborn |

## Skills and tools
Python, pandas, NumPy, scikit-learn, Matplotlib, Seaborn, exploratory data analysis, feature engineering, one-hot encoding, log transforms, outlier handling, linear regression, k-fold cross-validation, model fairness.
